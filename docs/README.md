# Project page

GitHub Pages site for the HDiT-Stereo paper (serve this `docs/` folder).

* `page.html` is the source; `index.html` is the same page wrapped in a full HTML document.
  After editing `page.html`, regenerate `index.html` by wrapping it the same way.
* `assets/figures/` holds the paper figures (WebP, max width 1800 px).
* `assets/explorer/` holds the result explorer's data: one 8 x 6 tile sheet per scene
  (`scene_XX.png`, 128 px tiles) and `scenes.json` with per-panel EPE / Bad-2.
